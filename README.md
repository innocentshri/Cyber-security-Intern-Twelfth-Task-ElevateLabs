## What are Logs?
Logs are records of events generated by operating systems, applications, and network devices.  
They provide detailed information about system activity, user actions, errors, and security events.

---

## Types of Logs

| Log Type | Description |
|-------|------------|
| Authentication Logs | User login and logout activity |
| System Logs | OS events and errors |
| Application Logs | Application-specific events |
| Security Logs | Security-related activities |

---

## Authentication Log Analysis
Authentication logs are used to:
- Monitor login attempts
- Identify failed logins
- Detect brute-force attacks
- Track user access behavior

Repeated failed login attempts may indicate unauthorized access attempts.

---

## Identifying Failed Login Attempts
Failed logins can be detected by:
- Multiple login failures from the same IP
- Login attempts outside normal working hours
- Repeated attempts on a single account

Such patterns are considered suspicious.

---

## Anomaly Detection
Anomaly detection involves identifying unusual patterns in logs that differ from normal behavior, such as:
- Sudden spikes in login failures
- Unknown IP addresses accessing the system
- Unexpected service restarts

---

## Event Correlation
Event correlation is the process of linking multiple log events to identify security incidents.

Example:
- Multiple failed logins  
- Followed by a successful login  
- From the same IP address  

This may indicate a brute-force attack.

---

## SIEM Basics
SIEM (Security Information and Event Management) systems:
- Collect logs from multiple sources
- Correlate events
- Generate alerts
- Support incident response

Examples include Splunk, ELK Stack, and QRadar.

---

## Writing Security Alerts
Alerts are generated when:
- Login failure thresholds are exceeded
- Suspicious behavior is detected
- Critical system events occur

Alerts help security teams respond quickly to incidents.

---

## Importance of Log Monitoring
Log monitoring is important because it:
- Helps detect security incidents early
- Supports forensic investigations
- Improves visibility into system activity
- Strengthens overall security posture

---

## Ethical Considerations
All log analysis activities are performed:
- On authorized systems
- For educational purposes
- Without accessing sensitive personal data
